# dsh-progress-payment

> **Repositorio oficial. El único repositorio oficial de este paquete, mantenido por PerryLink. Apache-2.0.**

</div>

Audita una declaración de pago por avance de obra contra la línea base del contrato: importes en céntimos enteros, ratio acumulado y lista de problemas (exceso de cantidad, precio distinto, partidas duplicadas), con exportación a CSV. Todo se ejecuta localmente.

La documentación completa (instalación, permisos, ejemplos y solución de problemas) está en [README.md](README.md) y [README-zh.md](README-zh.md).
